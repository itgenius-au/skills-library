# Quick mode details

Placeholders (`<REVIEW_SKILLS>`, `<SCRATCH>`, `<PROJECT_DIR>`, `<snapshot>`, `<RANGE>`) are defined in SKILL.md under "Invocation form". In this file, "each wrapper command from Step 3" means the commands in `references/orchestrator-run-legs.md`.

- **A large inlined packet.** With a 30-48 KB packet inlined into every leg's prompt, Gemini and Fable timed out at 570 s in most quick panels, so a panel ran on 2 legs. Keep the inlined packet for GLM only. Give the repo-capable legs (Codex, Gemini, Fable) a short prompt that names the files or the diff file to read, and report a 2-leg panel as degraded. Inline into the GLM packet every file the review questions depend on, up to the 60 KB cap; when the plan names more files than fit, say in the packet which files were left out. A GLM leg that is shown 2 of the 6 files a plan review asks about can only report the other 4 as unverified.
- **Codex on a large repo (code mode).** In a repo with many skills or packages, run the Codex leg through `<REVIEW_SKILLS>/review-with-codex/snapshot-review.sh --repo <repo> --sha <commit> --prompt-file <file> --out <file> --effort xhigh --timeout 570` instead of `codex-exec.sh --dir <repo>` (pass `--effort xhigh`: the script's default is `high`), and tell it in the prompt to read `change.diff` and only the files you name. `<commit>` is a committed checkpoint: commit the subject first, as Step 3 asks for every snapshot. With `--dir <repo>`, Codex at `xhigh` can use its whole 570 s reading unrelated history (a very large output and no `MODEL:` line), even after the prompt names one folder. If it still prints `::CODEX-TIMEOUT::`, the leg is `unavailable` (one attempt); for a PR, a Codex PR review is the independent read that stands in for it.
- **When you cannot run background calls** (a bound, unattended session whose rules ban background Bash), run the four orchestrator-run legs from ONE foreground runner script: it starts each wrapper command from Step 3 with `&`, then runs `wait`, then prints each output file's size and `MODEL:` line. Each wrapper has `--timeout 570`, so the one call fits the 10-minute Bash cap; give it the 600000 ms timeout. Record a failed leg and synthesize from the others.
